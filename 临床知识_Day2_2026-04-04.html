1. 支气管哮喘 Bronchial Asthma

定义

支气管哮喘是一种以慢性气道炎症、气道高反应性和可逆性气流受限为特征的异质性疾病。临床表现为反复发作的喘息、气短、胸闷和咳嗽，症状往往在夜间和清晨加重。

流行病学

全球约有3亿哮喘患者，中国20岁以上成人哮喘患病率约为4.2%，总数约4570万。儿童患病率呈上升趋势，约10-15%。

病理生理

  • 气道炎症：嗜酸性粒细胞浸润为主，IgE介导的I型变态反应
  • 气道高反应性（AHR）：气道对多种刺激因素出现过强的收缩反应
  • 气道重塑：长期炎症导致气道壁增厚、平滑肌增生、黏液腺肥大
  • 可逆性气流受限：支气管舒张试验阳性（FEV1改善≥12%且绝对值增加≥200ml）
核心机制：Th2细胞介导的过敏反应 → 嗜酸性粒细胞浸润 → 气道高反应性 + 可逆性气流受限

临床表现

  • 典型三联征：喘息、咳嗽、胸闷
  • 发作特点：夜间/清晨加重，季节性或接触过敏原后发作
  • 体征：呼气相延长、双肺满布哮鸣音（危重时可消失"寂静胸"）
  • 特殊类型：咳嗽变异性哮喘（CVA）、胸闷变异性哮喘（CTVA）、运动性哮喘

诊断标准

检查项目意义阳性标准
支气管舒张试验评估可逆性气流受限FEV1改善≥12%且绝对值增加≥200ml
PEF日内变异率评估气流受限波动连续2周PEF变异率≥20%
支气管激发试验评估气道高反应性乙酰甲胆碱PC20≤8mg/ml
呼出气一氧化氮（FeNO）嗜酸性气道炎症标志物>25ppb（提示Th2炎症）

治疗方案

GINA 2025 阶梯治疗方案（5步）
  • Step 1（轻度间歇）：按需吸入SABA（如沙丁胺醇）
  • Step 2（轻度持续）：低剂量ICS（如布地奈德）+ 按需SABA
  • Step 3（中型）：低剂量ICS/LABA（如信必可）维持
  • Step 4（中重度）：中剂量ICS/LABA，必要时加用LAMA
  • Step 5（重度）：高剂量ICS/LABA + 考虑生物制剂（奥马珠单抗、美泊利珠单抗等）

急性发作处理

  • 轻-中度：雾化吸入SABA（如沙丁胺醇0.5-1ml + 生理盐水），每20分钟可重复；口服泼尼松龙0.5-1mg/kg
  • 重度-危重：持续雾化SABA + 静脉甲泼尼龙40-80mg q6-12h；必要时机械通气
警示信号：寂静胸、意识改变、血氧饱和度<90%、说话不能成句 → 立即住院！

随访管理

  • 每1-3月评估症状控制（ACT评分）及肺功能
  • 避免过敏原暴露，戒烟
  • 患者教育：正确使用吸入装置，书面哮喘行动计划
  • 目标：达到并维持临床控制，维持正常活动能力
2. 慢性阻塞性肺疾病 COPD

定义

COPD是一种以持续性气流受限为特征的可以预防和治疗的疾病，气流受限呈进行性发展，与气道和肺对有毒颗粒或气体的慢性炎症反应增强有关。

流行病学

全球约3.8亿COPD患者，中国40岁以上人群患病率13.7%，约1亿患者。全球第三大死因，年死亡约300万。

病理生理

  • 吸烟（最重要危险因素）：导致中性粒细胞、巨噬细胞浸润，蛋白酶-抗蛋白酶失衡
  • 小气道病变：气道狭窄、纤维化；肺气肿：肺泡壁破坏（α1-抗胰蛋白酶缺乏相关年轻患者）
  • 通气/血流比例失调：低氧血症主要机制
  • 呼气气流受限：小气道在呼气相提前关闭，导致气体陷闭（air trapping）
核心特征：持续性气流受限（不完全可逆）+ 肺气肿/小气道病变 → 气体陷闭 + 通气/血流失调

临床表现

  • 慢性咳嗽：晨起明显，伴痰液（白色黏液痰为主）
  • 进行性呼吸困难：活动后加重，"气短"为主要就诊原因
  • 桶状胸、语颤减弱、叩诊过清音、呼吸音降低
  • 急性加重（AECOPD）：咳嗽、痰量增多、脓性痰、呼吸困难加重

诊断标准

指标意义诊断切点

CAT评分生活质量影响0-40分

治疗方案

稳定期治疗

  • A组：支扩剂（长效或短效SAMA/SABA）
  • B组：LABA + LAMA（双联长效支气管扩张）
  • C/D组：LABA + LAMA，D组加用ICS（血嗜酸粒细胞≥300/μl时ICS获益更大）

急性加重处理

  • 抗感染：脓性痰 + 呼吸困难加重 → 抗生素（阿莫西林/克拉维酸、左氧氟沙星）
  • 支气管舒张：雾化SABA + SAMA
  • 糖皮质激素：口服泼尼松龙30-40mg/d，5-7天
  • 氧疗：目标SpO2 88-92%
  • 通气支持：严重者NIV或IPPV
COPD-哮喘重叠（ACO）：患者同时具有哮喘和COPD特征，嗜酸粒细胞增高，ICS治疗获益明显。需谨慎排除哮喘-COPD重叠后再做诊断。

随访管理

  • 戒烟是最重要干预（药物：伐尼克兰、安非他酮）
  • 肺康复：运动训练 + 教育
  • 流感/肺炎疫苗接种
  • 长期家庭氧疗（PaO2≤55mmHg或SpO2≤88%）
  • 评估合并症（心血管、骨质疏松、焦虑抑郁）
3. 社区获得性肺炎 CAP

定义

社区获得性肺炎是指在医院外获得的感染性肺实质炎症，包括在入院后48小时内发病的肺炎。

流行病学

CAP年发病率5-11/1000人，成人住院患者死亡率6-10%，ICU患者可达25-50%。是65岁以上老年人首位感染性死因。

常见病原体

类型常见病原体
典型病原体肺炎链球菌（30-50%）、流感嗜血杆菌、卡他莫拉菌
非典型病原体肺炎支原体（20-30%，青年人）、肺炎衣原体、军团菌
病毒流感病毒（季节性）、RSV、鼻病毒、腺病毒
少见病原体铜绿假单胞菌（结构性肺病、ICU）、金黄色葡萄球菌（流感后）
临床鉴别：典型肺炎（急起高热、寒战、脓痰、肺实变体征）与非典型肺炎（相对缓起、干咳、轻微体征、"游走性"浸润）的区别对初始经验性治疗选择至关重要。

诊断标准

  • 临床表现：咳嗽、咳痰、发热、胸痛、呼吸困难 + 肺部湿啰音
  • 影像学：胸部X线/CT显示新出现的浸润影、实变影或磨玻璃影
  • 实验室：血常规（WBC↑、NEU↑）、CRP/PCT升高
  • 重症标准（需住院）：CURB-65≥2分 或 符合任一主要标准

CURB-65评分

指标1分
Confusion（意识障碍）新出现
Urea（尿素）>7mmol/L
Respiratory rate（呼吸频率）≥30次/分
Blood pressure（血压）SBP<90mmHg 或 DBP≤60mmHg
65（年龄）≥65岁

评分含义：0-1分门诊治疗，2分住院评估，3-5分住院治疗（死亡率显著升高）

治疗方案

经验性抗生素选择（中国成人CAP指南2024）
  • 门诊（无基础病）：阿莫西林或多西环素或大环内酯类（我国耐药率低）
  • 门诊（有基础病）：β内酰胺类 + 大环内酯类 或 呼吸喹诺酮（莫西沙星、左氧氟沙星）
  • 住院（非ICU）：β内酰胺类 + 大环内酯类 或 呼吸喹诺酮单药
  • 住院（ICU）：β内酰胺类（头孢曲松/头孢噻肟）+ 大环内酯类 或 呼吸喹诺酮

抗感染疗程

轻-中度：5-7天；重症：7-10天；铜绿假单胞菌/ MRSA：14-21天。退热48-72小时、临床稳定后可口服续贯治疗。

提醒：影像学吸收滞后于临床改善，不必为"肺部阴影未吸收"延长抗生素！

随访管理

  • 48-72小时评估治疗反应（体温、症状、氧合）
  • 影像学随访：6-8周后复查（吸烟者、老年患者需排除恶性肿瘤）
  • 疫苗：流感疫苗（每年）、肺炎球菌疫苗（PCV15/PCV20或PPSV23）
4. 肺血栓栓塞症 PTE

定义

PTE是来自静脉系统（右心）或右心的血栓堵塞肺动脉或其分支，导致肺循环和呼吸功能障碍的临床综合征。深静脉血栓形成（DVT）是主要栓子来源。

流行病学

年发病率约1-2/1000人，欧盟每年约30-40万例死亡。住院患者VTE风险增加10-100倍。是猝死第三常见原因。

危险因素（Virchow三联征）

  • 静脉瘀滞：长期卧床、制动、肥胖、怀孕
  • 血管内皮损伤：手术、创伤、中心静脉置管
  • 高凝状态：恶性肿瘤、抗磷脂综合征、遗传性血栓倾向、肾病综合征

病理生理

  • 血流动力学：肺血管阻力↑ → 右心压力↑ → 右心功能不全 → 左心前负荷↓ → 低血压/休克
  • 气体交换：通气/血流失调 + 肺泡无效腔↑ → 低氧血症
  • 心脏：右心室壁张力↑ → 心肌缺血（ coronary perfusion ↓）
临床线索：不明原因呼吸困难 + 心动过速 + 低氧血症 + 单侧下肢肿胀 → 需排查PTE

临床表现

  • 症状：呼吸困难（最常见）、胸痛（多为胸膜性）、咯血、晕厥、心悸
  • 体征：呼吸急促、心率快、血压下降、颈静脉怒张、P2亢进、三尖瓣返流杂音
  • DVT体征：单侧下肢肿胀、压痛、皮温增高

诊断标准

诊断流程：疑诊（临床评估）→ 确诊（影像学）→ 评估严重程度（血流动力学）

疑诊评估（ Wells评分）

项目分数
临床症状DVT（下肢肿、压痛）3.0
PTE可能性大于DS或 Ds或心率>100bpm1.5
制动或近4周手术史1.5
既往DVT/PE病史1.5
咯血1.0
恶性肿瘤1.0

>4分高度可能，≤4分低度可能

确诊检查

  • CT肺动脉造影（CTPA）：首选，敏感性95%，特异性90%
  • V/Q显像：用于CTPA禁忌或肾功能不全患者
  • 肺动脉造影：金标准，有创，复杂病例

血流动力学评估

指标高危PTE（休克/低血压）非高危PTE
血压SBP<90mmHg 或↓>40mmHg血压正常
右心功能CTPA/TEE显示右心增大无右心功能不全
心肌标志物cTnI/H、BNP显著升高正常或轻度升高

治疗方案

抗凝治疗（所有PTE均需）

  • 初始抗凝：低分子肝素（LMWH，如依诺肝素1mg/kg q12h）或磺达肝癸钠或普通肝素（ICU、血小板波动大）
  • 口服抗凝：DOAC（利伐沙班20mg qd、阿哌沙班5mg bid、达比加群150mg bid + LMWH桥接）
  • VKA（华法林）：需LMWH桥接，INR 2-3

溶栓治疗（高危PTE）

  • 适应证：血流动力学不稳定（休克、SBP<90mmHg）、心脏骤停
  • 药物：tPA 100mg 静脉滴注2小时 或 尿激酶
  • 绝对禁忌：活动性出血、近期颅内出血

介入/手术治疗

溶栓禁忌或失败 + 血流动力学恶化 → 导管取栓或手术取栓

注意：对于高危PTE合并心脏骤停/呼吸衰竭患者，如家属理解病情，可考虑ECMO支持！

随访管理

  • 抗凝疗程：诱因明确（手术/制动）3-6月；不明原因6-12月；肿瘤/抗磷脂综合征/复发则长期抗凝
  • 定期复查下肢超声（评估DVT消退）
  • 急性期后复查CTPA（评估血栓溶解情况）
  • 弹力袜（左踝-大腿，压力梯度）改善血栓后综合征
